# Productividad e invasión de enfriadores

Página informativa para clientes que cuentan con un enfriador en su punto de venta.

## Archivos separados

- `index.html`: estructura, textos, marcas y enlaces de WhatsApp.
- `style.css`: diseño adaptable a teléfonos, estilos y animaciones visuales.
- `app.js`: saludo según la hora, fecha, reloj y animación ilustrativa de las barras.

## Publicación con GitHub Pages

En el repositorio, abre **Settings → Pages** y selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda los cambios y espera a que GitHub publique el sitio.

## Nota sobre la gráfica

La gráfica es una ilustración animada, no un reporte de ventas ni una meta comercial oficial. Los objetivos reales deben confirmarse con el representante comercial correspondiente.
